# Phase 1 Study Plan: JavaScript Fundamentals (2-4 Weeks)

## 1) Overview and Phase Goals

The goal of **Phase 1** is to build a rock-solid foundation in core JavaScript fundamentals before advancing to DOM manipulation, Asynchronous JavaScript, or Web Frameworks.

By the end of this phase, you will have mastered:
- Variable declarations, scope rules, and memory behavior.
- JavaScript's type system, implicit coercion, and equality semantics.
- Decision patterns, loops, and function architecture (Pure vs. Impure functions).
- Higher-Order Array methods (`map`, `filter`, `reduce`), Objects, `Set`, and `Map`.
- Built-in utility APIs (`Math`, `Date`, `Intl`) and `try...catch` error handling.
- Building 3 complete browser-based mini-projects.

---

## 2) Track Selection

Choose the learning track that best fits your daily availability and prior programming experience:

- **Fast Track (2 Weeks)**: 3 to 4 hours/day. Recommended if you already have programming experience in another language.
- **Standard Track (4 Weeks)**: 1.5 to 2 hours/day. Recommended for thorough learning, deep practice, and optimal memory retention.
