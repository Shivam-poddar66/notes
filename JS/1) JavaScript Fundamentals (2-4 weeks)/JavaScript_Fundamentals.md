# JavaScript Fundamentals (Phase 1)

Last updated: February 25, 2026
Target duration: 2-4 weeks

## Chapter Goal
Build a strong base in JavaScript syntax, control flow, functions, collections, core built-in objects, and error handling.

## What This Chapter Covers
- Syntax and core language basics.
- Data types, coercion, and comparisons.
- Operators and modern syntax features.
- Control flow and loops.
- Functions, parameters, scope, and purity.
- Arrays, objects, sets, maps, and common methods.
- Strings, numbers, math utilities, date basics.
- Error handling fundamentals.
- Exercises and mini-projects for milestone completion.
