1. 40 min concept reading.
2. 60 min code experiments.
3. 30 min debugging and note writing.
4. 20 min explain-out-loud recap.

- 3 mini-projects done.
- You can explain `this`, closure, and prototypes without notes.
- You can debug 5 intentionally broken snippets.
