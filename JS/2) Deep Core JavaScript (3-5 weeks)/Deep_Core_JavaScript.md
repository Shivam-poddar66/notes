# Deep Core JavaScript (Phase 2)

Last updated: February 25, 2026
Target duration: 3-5 weeks

## Chapter Goal
Master JavaScript internals: execution model, closures, `this`, prototypes, object internals, modules, and advanced language behavior.

## What This Chapter Covers
- Execution context, call stack, hoisting, TDZ, lexical environment.
- Closures, closure pitfalls, and debugging closure bugs.
- `this` behavior across invocation patterns.
- Prototypal inheritance and ES6 classes under the hood.
- Property descriptors and object integrity controls.
- Shallow/deep copy strategies.
- ESM vs CommonJS and module design.
- Tree-shaking and side-effects mindset.
- Iterators, generators, symbols, and advanced patterns.

## Completion Standard
You complete Phase 2 when you can:
- Explain execution context, closures, `this`, and prototype chain without notes.
- Implement mini event emitter and polyfills correctly.
- Design a modular app with clean import/export boundaries.
- Debug `this`, hoisting, and closure issues in real code.

## Required Milestone Projects
1. Custom Event Emitter
2. Simple Module-Based App
3. Polyfills for `map`, `filter`, `reduce`

## Study Rule
Understand internals -> predict behavior -> run code -> debug edge cases -> explain aloud.
