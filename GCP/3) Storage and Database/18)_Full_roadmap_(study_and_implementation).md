# 18) Full Roadmap (Study And Implementation)

Last updated: February 24, 2026  
Target: Google Cloud Associate Cloud Engineer (ACE)

## Roadmap objective
Build production-level understanding of GCP storage and database services with exam-ready decision speed.

## Phase 1: Foundation (Day 1 to Day 3)
### Goals
- Understand data models and service boundaries.
- Build a single-page service mapping chart.

### Tasks
1. Study object, block, and file storage differences.
2. Study relational, document, wide-column, and analytics database models.
3. Memorize core service fit:
   - Cloud Storage,
   - Cloud SQL,
   - Spanner,
   - Firestore,
   - Bigtable,
   - BigQuery,
   - Memorystore.

### Deliverable
- One comparison matrix with "when to use" and "avoid when" columns.

## Phase 2: Service deep dives (Day 4 to Day 8)
### Goals
- Build deeper intuition per service.

### Tasks by day
- Day 4: Cloud Storage + lifecycle + retention.
- Day 5: Cloud SQL + reliability and private connectivity.
- Day 6: Spanner + selection boundary vs Cloud SQL.
- Day 7: Firestore + Bigtable comparison.
- Day 8: BigQuery + cost/performance patterns.

### Deliverable
- One summary note per service with architecture, security, reliability, cost, and exam cues.

## Phase 3: Cross-cutting skills (Day 9 to Day 11)
### Goals
- Learn security, DR, and cost governance as overlays.

### Tasks
1. Build IAM least-privilege mapping by service.
2. Define backup and restore policy by data tier.
3. Build cost and monitoring dashboard checklist.

### Deliverable
- Reusable architecture review checklist.

## Phase 4: Scenario and exam pattern mastery (Day 12 to Day 14)
### Goals
- Answer scenario questions quickly with high accuracy.

### Tasks
1. Solve 40+ mixed storage/database scenarios.
2. Practice elimination method under time limit.
3. Review each wrong answer by root-cause category.

### Deliverable
- Personal "trap pattern" list with corrections.

## Phase 5: Hands-on labs and integration (Day 15 to Day 18)
### Goals
- Validate design decisions by implementation.

### Tasks
1. Run mini labs from Topic 19.
2. Build integrated architecture using at least 3 data services.
3. Document design tradeoffs and operational controls.

### Deliverable
- Lab evidence set and architecture decision record.

## Phase 6: Final revision sprint (Day 19 to Day 21)
### Goals
- Consolidate memory and improve speed.

### Tasks
1. Review quick revision sheet daily.
2. Reattempt hardest scenario sets.
3. Run one full mock with strict timing.

### Deliverable
- Final revision notes and weak-area closure list.

## Weekly rhythm recommendation
- 60 to 90 minutes weekdays.
- 2 to 3 hours weekend lab block.
- End each week with a timed mini-assessment.

## Progress metrics
Track:
- scenario accuracy percentage,
- time per question,
- labs completed,
- number of unresolved weak topics.

## Completion criteria
You are ready when:
- service selection is consistently constraint-driven,
- you can justify every decision in one minute,
- you can identify trap options quickly.

## One-line memory hook
Roadmap success equals theory + labs + timed scenarios + correction loop.
