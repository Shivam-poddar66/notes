# DSA Mastery Roadmap (Complete)

This roadmap is your complete chapter-wise path to master DSA.
Use it with the phase folders and topic files in this DSA directory.

Last updated: February 25, 2026

## How to Use This Roadmap

- Study 2-4 hours/day, 5-6 days/week.
- For every topic: learn -> implement -> solve timed problems -> review mistakes.
- Do not skip revision cycles (1 day, 7 day, 30 day).
- Move to next phase only after milestone and target count checks.

## Mastery Standard

You are strong in DSA when you can:

- Identify the right pattern in 3-5 minutes for new medium problems.
- Implement optimized solutions with low bug rate in timed settings.
- Explain correctness and complexity without notes.
- Combine multiple patterns for hard problems.
- Maintain long-term retention via revision and mock loops.

## Phase-Wise Plan

### Phase 0 (2-3 days)
- Setup and DSA learning system, tracking, routine, and quality bar.

### Phase 1 (1-2 weeks)
- Complexity, proofs, constraints, and problem-solving framework.

### Phase 2 (2-3 weeks)
- Arrays, strings, hashing, matrix patterns, and subarray optimizations.

### Phase 3 (2-3 weeks)
- Two pointers, sliding windows, prefix and difference techniques.

### Phase 4 (2-3 weeks)
- Linked lists, stacks, queues, deques, and design patterns like LRU.

### Phase 5 (2-3 weeks)
- Recursion, backtracking, pruning, divide-and-conquer, quickselect.

### Phase 6 (2-3 weeks)
- Sorting families, searching templates, and binary search on answer.

### Phase 7 (3-4 weeks)
- Trees, BST, heaps, LCA, rerooting basics, and hierarchical patterns.

### Phase 8 (3-4 weeks)
- Graph modeling, BFS/DFS, DSU, topological sort, and cycle logic.

### Phase 9 (3-5 weeks)
- Dijkstra, Bellman-Ford, Floyd-Warshall, MST, SCC, bridges, max-flow intro.

### Phase 10 (3-4 weeks)
- Dynamic programming foundations: 1D/2D/state transitions/core families.

### Phase 11 (4-6 weeks)
- Advanced DP: tree DP, bitmask DP, digit DP, DP optimizations.

### Phase 12 (3-4 weeks)
- Tries and string algorithms: KMP, Z, rolling hash, Aho-Corasick, suffix overview.

### Phase 13 (2-3 weeks)
- Bit manipulation, modular math, number theory, combinatorics.

### Phase 14 (4-6 weeks)
- Advanced DS: Fenwick, segment tree, sparse table, Mo, HLD, persistence intro.

### Phase 15 (Ongoing)
- Interview and contest mastery loop, mocks, communication, revision engine.
