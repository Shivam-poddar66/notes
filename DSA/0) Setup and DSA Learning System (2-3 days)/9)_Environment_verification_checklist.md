# Environment Verification Checklist

Last updated: February 26, 2026  
Phase: Setup and DSA Learning System (Phase 0)

## Goal
Verify that your tooling is stable before starting high-volume practice.

## Compiler and Runtime Checks
- [ ] Primary language runtime/compiler is installed.
- [ ] Version command works from terminal.
- [ ] Build/run command works inside your project folder.

## Editor Workflow Checks
- [ ] You can run current file with one shortcut.
- [ ] You can open terminal in project root quickly.
- [ ] Snippet/template insertion works.
- [ ] Auto-format and lint (if used) do not break templates.

## Template Checks
- [ ] Main template compiles with no edits.
- [ ] Fast I/O setup works on large input.
- [ ] Helper utilities (gcd, BFS, binary search helper) compile.

## Testing Workflow Checks
- [ ] Sample input test file runs successfully.
- [ ] Expected-output comparison script works.
- [ ] Stress test script runs on at least one toy problem.

## Git and Backup Checks
- [ ] Repository initialized.
- [ ] First commit created.
- [ ] Remote backup configured (if you use remote hosting).

## Pre-Session 3-Minute Verification
1. Pull latest notes/templates.
2. Run one quick compile and sample test.
3. Open tracker and today's target list.

## Exit Criteria
- [ ] All checklist groups pass.
- [ ] You can begin a timed problem in under 2 minutes from opening the editor.
