# Phase 0 Study Plan (2-3 days)

Last updated: February 26, 2026  
Phase: Setup and DSA Learning System (Phase 0)

## Goal of Phase 0
Finish setup so Phase 1 onward can focus on learning, not tooling friction.

## Day 1: Environment and Repository Setup
- Finalize primary language choice.
- Create `dsa-templates` repository structure.
- Add main template, fast I/O, and run script.
- Run sample compile/execute checks.
- Create baseline tracker sheet.

Expected output:
- Working repository + one successful end-to-end run.

## Day 2: Learning System Setup
- Create note template and mistake log format.
- Define daily routine and weekly rhythm.
- Configure spaced repetition queue (D+1, D+3, D+7, D+30).
- Solve 2 easy + 1 medium timed to collect baseline metrics.

Expected output:
- Note system live + first real entries in logs and dashboard.

## Day 3 (Optional but Recommended): Validation and Calibration
- Run a 90-minute mixed timed session.
- Review all mistakes and produce prevention rules.
- Finalize pre-submit checklist and recovery protocol.
- Adjust weekly targets based on real baseline.

Expected output:
- Stable system with measurable targets for next phase.

## Minimum Completion Criteria
- [ ] Toolchain works with one-command run.
- [ ] Templates and scripts are in place.
- [ ] Tracker, mistake log, and revision queue are active.
- [ ] At least 3 timed problems completed in this phase.
