# Progress Dashboard and Scoring Method

Last updated: February 26, 2026  
Phase: Setup and DSA Learning System (Phase 0)

## Goal
Track preparation objectively so decisions are based on data, not mood.

## Core Metrics
- Problems attempted.
- Problems solved correctly.
- First-attempt acceptance rate.
- Average solve time by difficulty.
- Hint dependency rate.
- Re-solve success rate.

## Weekly Scoring Formula (100 Points)
- Accuracy (30 points): `30 * (correct / attempted)`.
- Speed (20 points): based on median time against your target.
- Independence (20 points): lower hint usage gives higher score.
- Retention (20 points): D+7 and D+30 re-solve results.
- Discipline (10 points): planned sessions completed.

## Decision Rules from Score
- 80 to 100: continue with current pace and add more medium/hard.
- 65 to 79: maintain pace but prioritize weak tags.
- Below 65: reduce new volume and focus on review + fundamentals.

## Non-Negotiable Trend Checks
- Accuracy should trend up across 3 weeks.
- Hint dependency should trend down.
- Retention should not fall while volume rises.
