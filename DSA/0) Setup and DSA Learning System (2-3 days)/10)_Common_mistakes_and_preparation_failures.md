# Common Mistakes and Preparation Failures

Last updated: February 26, 2026  
Phase: Setup and DSA Learning System (Phase 0)

## Goal
Prevent avoidable preparation failures before they become long-term habits.

## High-Impact Mistakes
- Solving many problems but logging no mistakes.
- Switching language or platform too often.
- Reading editorials too early.
- Ignoring re-solve cycles.
- Measuring only volume, not accuracy or speed.
- Skipping edge-case testing under time pressure.

## Root Causes and Fixes
### Mistake: Random practice with no system
- Root cause: no weekly plan and no defined targets.
- Fix: set weekly problem mix, revision blocks, and score targets.

### Mistake: Repeated same bug type
- Root cause: no postmortem or preventive checklist.
- Fix: maintain mistake taxonomy and pre-submit checklist.

### Mistake: Burnout after short high-intensity streak
- Root cause: unrealistic daily load.
- Fix: use minimum effective session on low-energy days.

### Mistake: False confidence from copied solutions
- Root cause: passive reading, no active recall.
- Fix: re-solve without notes after D+3 and D+7.

## Warning Signals
- Accuracy dropping for 2+ consecutive weeks.
- Hint dependency increasing.
- Large backlog of unsolved re-solve tasks.
- Fear of timed sessions.

## Recovery Protocol (If Stuck)
1. Pause new hard problems for 3 to 5 days.
2. Re-solve recent failed easy/medium set.
3. Rebuild confidence with clean checklist-driven solves.
4. Resume normal mix only after metrics stabilize.

## Exit Criteria
- [ ] You identified your top 5 likely mistakes.
- [ ] Each mistake has one prevention rule.
- [ ] Recovery protocol is written in your tracker.
